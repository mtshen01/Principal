🔧 技术实现细节
实现要点

API 文档替换

  • 前端改动：每条文档加"🔄"按钮
  • 参数化上传：替换时用 `doc.name`，新增用 `file.name`
  • 后端识别：按 `name` 主键，自动判断"更新"或"新增"
  • 复用流程：现有两段式上传、epoch 守卫、refreshRail

设计准则移除

  • 前端改动：删除输入框+按钮（4-5 行）
  • 后端保留：`designGuidelines` 字段、PUT 路由
  • 提示词保留：历史值仍会注入给 Claude
  • 数据风险：零——仅删除 UI，后端完全兼容
