怎么拿 Claude 订阅 Key
  1. 本机先装好并登录 Claude Code CLI（终端里 claude 命令可用）。
  2. 在终端执行下面这条命令：
claude setup-token
  1. 按提示在浏览器完成授权，终端会打印一串以 sk-ant-oat01- 开头的 key。
  2. 整串复制，粘到左侧输入框，点「＋ 添加」。
多个账号都加进来即可自动轮换：某个号额度耗尽时会切到下一个，不必手工换。
