# Markdown 查看工具设计文档

**日期**：2026-08-14  
**功能**：在 VIBE CODING 中新增 Markdown 文件查看工具，支持预览、目录导航、搜索、导出

---

## 概述

在现有工具系统（JSON 工具、记忆库）基础上新增 **Markdown 查看工具**，用户可通过拖拽或文件按钮打开 `.md` 文件，工具提供实时渲染、目录导航、搜索、导出功能，整体风格遵循现有主应用配色和深色/浅色主题自适应。

---

## 核心需求

| 需求 | 说明 |
|------|------|
| **文件打开** | 支持拖拽 `.md` 文件 + 点击"打开文件"按钮两种方式 |
| **内容渲染** | 完整 Markdown 渲染（标题、列表、代码块、表格等），已有 marked.js + DOMPurify vendor 支持 |
| **文件路径显示** | 工具顶部显示当前打开文件的完整路径 |
| **目录大纲（TOC）** | 左侧折叠面板显示标题树（h1-h6），支持展开/折叠，点击跳转 |
| **搜索功能** | 快速查找文件内容关键词，高亮匹配项 |
| **导出功能** | 支持导出为 HTML、复制全文等操作 |
| **文件历史** | 侧栏显示打开过的文件列表，单次打开替换显示 |
| **主题一致性** | 使用现有 VIBE CODING 配色、字体，自动适配深色/浅色模式 |

### 2. 核心组件

#### 2.1 工具入口
- **侧栏工具按钮**：类似 JSON 工具，添加 `id="toolMarkdown"` 的 `.tool-item`
  - 图标：`📄`
  - 标题：`Markdown 查看工具`
  - 描述：`预览 · 搜索 · 导出`
- **打开历史列表**：在工具列表下方展示最近 10 个打开过的文件
  - 点击文件项重新打开
  - 显示文件名 + 修改时间

#### 2.2 工具面板（panel-page）
- **html 模板**（`public/index.html` 新增）：
  ```html
  <div class="panel-page" data-view="markdown" hidden>
    <div class="panel-head">
      <h3>Markdown 查看工具</h3>
      <button class="panel-close" title="返回对话">✕</button>
    </div>
    <div id="markdownBody"></div>
  </div>
  ```
- **JavaScript 模块**（`public/js/markdown-tool.js`）：
  - 文件拖拽处理
  - 文件读取与渲染
  - 目录树生成
  - 搜索逻辑

#### 2.3 左侧目录面板
- **结构**：使用树形菜单，支持多级展开/折叠
- **交互**：
  - 点击标题项，页面平滑滚动到对应位置
  - 当前视口内的标题高亮显示
  - 目录可完全折叠，节省空间

#### 2.4 内容渲染区域
- **Markdown 渲染**：
  - 使用现有 `marked.js` + `DOMPurify`
  - 支持 GFM（GitHub Flavored Markdown）扩展
  - 代码块带语言标识，使用现有项目的代码块样式
- **路径显示**：文件完整路径 + 文件大小 + 修改时间
- **工具栏**：
  - 搜索框（Ctrl+F 快捷键）
  - "导出为 HTML" 按钮
  - "复制全文" 按钮

#### 2.5 搜索功能
- **实现**：
  - 实时搜索，输入时高亮匹配项（黄色背景）
  - 显示匹配数量 `n 个匹配项`
  - 支持大小写敏感开关
  - 支持正则表达式（可选，初版不需要）
- **快捷键**：`Ctrl+F` 打开搜索框，`Esc` 关闭

#### 2.6 导出功能
- **导出 HTML**：
  - 将渲染结果保存为独立 HTML 文件（可离线查看）
  - 包含内联 CSS，保留样式
- **复制全文**：
  - 复制渲染后的纯文本或 Markdown 原文

## 数据流

### 文件打开流程

```
用户拖拽 .md 文件 / 点击"打开文件"
  ↓
验证文件格式（.md 后缀 + 文件大小 < 10MB）
  ↓
调用 Tauri API 读取文件内容（fs::read_to_string）
  ↓
生成目录树（递归扫描 h1-h6 标题）
  ↓
Markdown → HTML（marked.parse）
  ↓
DOMPurify 清理 HTML（防 XSS）
  ↓
渲染到 #markdownBody
  ↓
更新打开历史（localStorage）
  ↓
侧栏显示新项目
```

### 搜索流程

```
用户输入搜索关键词
  ↓
遍历 DOM 节点，找到匹配文本
  ↓
使用 <mark> 标签包装匹配项
  ↓
更新计数器 & 高亮样式
  ↓
点击下一个/上一个，滚动到对应位置
```

## 错误处理

| 错误场景 | 处理方式 |
|---------|--------|
| 拖入非 .md 文件 | 显示 toast 提示：`仅支持 .md 文件` |
| 文件不存在 | 显示 toast：`文件已移除或无权限访问` |
| 文件大小 > 10MB | 显示 toast：`文件过大（> 10MB），请选择较小文件` |
| Markdown 解析失败 | 显示原文本 + 错误提示，避免白屏 |
| 浏览器不支持 File API | 降级到手动输入路径方式 |
