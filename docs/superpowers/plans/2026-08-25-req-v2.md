# 需求功能 v2 实现计划

对应 spec：`docs/superpowers/specs/2026-08-25-req-v2-design.md`

顺序原则：**纯逻辑先行（带单测）→ 存储 → 编排 → 路由 → 前端**。
三条能力按 A（最小闭环）→ B（主体）→ C（收尾）交付，每条落完即可单独验证。

---

## 验证方式

每个 P 段落完即可单独验证：
- P0–P1：`npm test` 全绿
- P4：开发期需求点开右栏，能弹框、能提交、对话流有回响
- P5：新建需求 → 生成开发文档 → 出问卷 → 答完出双报告 → 地图能标注能修订
- P6：地图页面节点挂 Figma URL → 触发还原 → 会话收到带规范约束的消息
