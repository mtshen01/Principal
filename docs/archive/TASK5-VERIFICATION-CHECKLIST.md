## 验收 1: 状态行动画

**目标**: 验证"⏳ 读取 / 执行"等状态文字的乱码→真实过程流畅

### 步骤

1. [ ] 打开 http://127.0.0.1:3001
2. [ ] 点击输入框
3. [ ] 输入: `你好`
4. [ ] 点击发送按钮
5. [ ] 观察消息气泡右上方的运行状态区域

### 检查点

- [ ] **动画触发**: 状态文字出现乱码（如"X&#@K$ / ^%*!~"）
- [ ] **乱码字符**: 使用英文大小写和数字混合（a-zA-Z0-9@#$%）
- [ ] **逐步变正**: 乱码逐字变为正常文字（如"⏳ 读取 / 执行"）
- [ ] **动画时长**: 整个过程约 500ms（不超过 1 秒）
- [ ] **落定平滑**: 最后一个字落定时无闪烁或突变
- [ ] **无异常**: 浏览器控制台无错误 (F12 检查)

### 成功标准

✅ **状态行验收**: 若上述 6 个检查点全部满足，则状态行验收通过

## 验收 2: 工具行动画

**目标**: 验证工具调用行（如"读取 xxx.js / 编辑 yyy.ts"）的无缝过渡

### 步骤

1. [ ] 在输入框输入编程相关的任务（例如）：
   ```
   帮我分析 src/app.js 的第 100 行，然后修改它
   ```
2. [ ] 点击发送按钮
3. [ ] 等待任务开始运行（约 2-3 秒）
4. [ ] 观察消息气泡右侧的工具行（工具调用日志）

### 检查点

对于每一个工具调用：

- [ ] **圆点常驻**: 最前面的 "●" 圆点保持不动
- [ ] **文字动画**: 圆点后的工具名称文字参与动画
- [ ] **首个工具**: 乱码 → 真实名称，约 500ms
  - 示例: "X%#@&^.js" → "app.js"
- [ ] **后续工具**: 前一个工具淡出/消失，新工具乱码 → 真实
  - 示例: 
    - 旧: "读取 app.js"
    - 新: "X%&# yyy.ts" → "编辑 yyy.ts"
- [ ] **无闪烁**: 文字切换时平滑，无突变
- [ ] **无重复**: 文字不会重复显示或重叠
- [ ] **无异常**: 浏览器控制台无错误

### 成功标准

✅ **工具行验收**: 若上述 7 个检查点全部满足，则工具行验收通过
