🔄 6 层降级机制详解：

  1️⃣  Token 轮换降级
      触发: Token 限流
      动作: 自动切换备用 Token
      位置: src/features/token-rotation.js
      恢复: 60 秒后自动尝试恢复

  2️⃣  Effort 参数降级  
      触发: 模型不支持 effort 等级
      动作: SDK 自动降级到低等级
      位置: src/integrations/claude.js
      恢复: 自动，应用层无感知

  3️⃣  模型分类降级
      触发: 任务分类超时（Haiku）
      动作: 降级到 medium effort
      位置: src/entrypoints/web/server.js
      恢复: 立即使用降级参数

  4️⃣  会话恢复降级
      触发: 应用崩溃
      动作: 自动保存进度，重启后恢复
      位置: src/store/pending-resume.js
      恢复: 启动时自动恢复

  5️⃣  通知平台降级
      触发: 非 Windows 平台
      动作: 降级为 console.log
      位置: src/integrations/notify.js
      恢复: 自动，无需配置

  6️⃣  自动压缩降级
      触发: 长会话消息堆积
      动作: 自动压缩历史消息
      位置: src/entrypoints/web/server.js
      恢复: 自动，节省 Token 20-40%
